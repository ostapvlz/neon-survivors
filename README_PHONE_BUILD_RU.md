# NEON SURVIVORS — сборка APK с телефона

Этот архив подготовлен для облачной сборки через GitHub Actions. Компьютер и установка Godot на телефон не нужны. GitHub собирает APK на своих серверах.

## Что понадобится
- iPhone/Android с браузером;
- аккаунт GitHub (бесплатного достаточно).

## Шаги
1. Откройте https://github.com и войдите или создайте бесплатный аккаунт.
2. Нажмите **+** → **New repository**.
3. Название: `neon-survivors`. Выберите **Public** или **Private**, затем **Create repository**.
4. На странице репозитория нажмите **Add file** → **Upload files**.
5. Распакуйте этот ZIP на телефоне через приложение «Файлы» (iPhone: откройте ZIP — появится папка). Загрузите ВСЕ файлы и папки из архива в корень репозитория. Важно: вместе с `project.godot` должны попасть `export_presets.cfg` и папка `.github/workflows`.
   - Если GitHub в мобильном браузере не показывает скрытую папку `.github`, включите в браузере «Версия для компьютера» или загрузите архив через веб-интерфейс GitHub, сохранив структуру папок.
6. Нажмите **Commit changes**.
7. Откройте вкладку **Actions** репозитория. Должен запуститься workflow **Build Android APK**. Если нет — откройте его и нажмите **Run workflow**.
8. Дождитесь зелёной галочки. Откройте завершённый запуск, прокрутите до **Artifacts** и нажмите **NEON-SURVIVORS-APK** — скачается ZIP с файлом `NEON_SURVIVORS.apk`.
9. Передайте APK на Android-телефон и откройте его для установки. Android может попросить разрешить установку из этого источника.

## Важно
- APK предназначен для Android и не устанавливается на iPhone.
- Это debug-сборка для проверки, не подписанный релиз для Google Play.
- Исходный проект — прототип; перед публикацией нужно протестировать игру на реальном Android-устройстве.
- Для публикации в Google Play потребуется отдельная release-сборка и собственная подпись (keystore). Не публикуйте keystore и пароли в открытом репозитории.
